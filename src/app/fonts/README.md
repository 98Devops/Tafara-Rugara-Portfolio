# Bundled portfolio fonts

Latin WOFF2 subsets of Archivo, Fraunces (normal and italic), and JetBrains Mono, retained from the successful Next.js Google Fonts build. Original font families are distributed under the included SIL Open Font License files from https://github.com/google/fonts/tree/main/ofl.

Bundling these files removes the Google Fonts network request during production builds. The existing font variables, weights and display behavior are preserved.
